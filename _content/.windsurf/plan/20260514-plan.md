## Plan SEO

### Mots-clés prioritaires par catégorie

#### Positionnement unique (différenciation forte)

- **Studio créatif ASBL Bruxelles** — unique sur le marché, crédibilité éthique
- **Graphiste intuitive Belgique** — atout Tess, peu de concurrence
- **Duo designer développeur Belgique** — complémentarité rare
- **Website builder indépendant** / **poko** — outil propriétaire = authority

#### Cible ASBL & impact

- **Création site web ASBL**
- **Site internet association Belgique**
- **Communication pour ONG éthique**
- **Web pour projet à impact**

#### Anti-concurrence (positionnement Marc)

- **Site web sans WordPress Belgique**
- **Site statique performant**
- **Alternative éthique WordPress**
- **Développeur web indépendant Bruxelles**

#### Localisation (SEO local)

- **Studio créatif Bruxelles**
- **Agence web Liège** / **Namur** (selon zone d'action)
- **Graphiste Bruxelles**

#### Longue traîne (intention forte, faible concurrence)

- **Refonte site web éco-conçu**
- **Site web thérapeute / coach Belgique**
- **Site artisan éthique**
- **Tarif site web ASBL transparent**
