# Rise for the Mind!

Création du site web de Rise for the Mind avec le site builder {% link url="https://www.poko.eco/", type="external" %}poko.eco{% endlink %}.

Le projet ne disposait au départ ni de logo ni de charte graphique. Il a donc fallu construire une première identité visuelle directement dans le cadre de la création du site.

Pour poser les bases de l’univers visuel, nous sommes partis de la couverture du livre écrit par Mark Hunyadi. La palette de couleurs et les choix typographiques ont été construits à partir de cette première référence afin de créer un site cohérent avec l’univers du projet.

Notre intervention

Direction artistique · palette de couleurs · recherche typographique · conception du site web · intégration avec poko.eco

Le petit+

Créer une identité visuelle à partir d’un élément déjà existant, puis la faire vivre directement dans un site web sans partir d’une charte graphique préétablie.

Un site associatif sur mesure, réalisé avec [poko](https://www.poko.eco/), pour une organisation engagée sur des sujets de santé mentale.

## Quelques points forts

- Design sur mesure
- Collection "People" personnalisée et triée dynamiquement
- [Graphe SVG éditable](https://www.mindthemind-now.org/objectif/) directement depuis le CMS
- [Excellent score au Website Carbon Calculator](https://www.websitecarbon.com/website/mindthemind-now-org/)
